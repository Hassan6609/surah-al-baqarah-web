📖 Surah Al-Baqarah – Interactive Web Application

A clean, responsive, and user-friendly frontend web application for reading and listening to “Surah Al-Baqarah” with synchronized Arabic recitation and Urdu audio translation.

🌐 **Live Demo:** https://hassan6609.github.io/surah-al-baqarah-web/


 Features :

- Synchronized Audio Playback:   Arabic recitation by Mishary Alafasy paired with Urdu translation audio.
- Smart Navigation:  Quick "Go to Ayat" jump feature (1–286) and continuous full-Surah playback.
- Flexible Audio Modes:  Switch between Arabic + Urdu, Arabic-only, and Urdu-only modes.
- Responsive Design:  Custom dark-emerald theme with proper RTL Arabic typography for desktop and mobile screens.
- State Persistence:  Saves user preferences locally using browser `LocalStorage`.

🛠️ Tech Stack

- HTML5 & CSS3 (Custom Arabic Typography & RTL Layout)
- JavaScript (ES6+) (Async/Await, DOM Manipulation, HTML5 Audio API)
- REST APIs:  Al Quran Cloud API & EveryAyah Audio API
- Hosting:  GitHub Pages
